# CS5830_Project5

## Getting Data
Data download: [https://drive.google.com/file/d/1WyADwoweynXDA1UmNCrSlxU9Vy08vNQY/view?usp=sharing]

- Download and extract the zip file from the link above.
- Create a `data/` folder in the project's root directory, and move the files into there.

Our original dataset came from: [https://www.kaggle.com/datasets/saurabhbagchi/books-dataset](https://www.kaggle.com/datasets/saurabhbagchi/books-dataset)

## Setting up Environment
```sh
conda create -n mh-cm-proj5 python=3.14
conda activate mh-cm-proj5
pip install -r requirements.txt
```
